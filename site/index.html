Was EasyTiley kann

Gebaut für Wand-Tablets und den Alltag – nicht für Konfigurationsdateien.

Freies Raster

Kacheln per Drag & Drop platzieren und skalieren, zu Karten verschmelzen, in Raum-Boxen gruppieren.

Echtzeit

FHEM-Push über Server-Sent-Events: Werte und Zustände ändern sich sofort, ohne Neuladen.

Erkennt deine Geräte

Readings und Set-Befehle werden automatisch erkannt – Gerät wählen, fertig.

Für Wand-Tablets

Vollbild, Vibration und Klick-Ton, Modus für schwache Tablets, dunkles und helles Design.

Bleibt bei dir

Keine Cloud, kein Konto, keine CDNs. HTTPS und Passwortschutz von FHEMWEB werden unterstützt.

Deutsch & Englisch

Die ganze Oberfläche zweisprachig, umschaltbar in den Einstellungen.

Installation

Du brauchst nur Docker. Danach im Browser unter ⚙ Einstellungen die FHEM-Adresse eintragen – fertig.

Installieren

git clone https://github.com/Glenn-Dandy/easytiley.git
cd easytiley
mkdir -p data && chmod 777 data
docker compose up -d --build
# → http://localhost:8080

Aktualisieren

cd easytiley
git pull
docker compose up -d --build
# Dashboards in data/fhem.db bleiben

Ausführliche Anleitung, Reverse-Proxy-Tipps und API im README.

Häufige Fragen

Was ist EasyTiley?

Ein Web-Dashboard für FHEM. Du stellst dir Kacheln für Lampen, Heizung, Rollläden, Sensoren, Wetter und Diagramme zusammen und bedienst dein Smart Home im Browser – am PC, Handy oder Wand-Tablet.

Was brauche ich dafür?

Einen laufenden FHEM-Server mit FHEMWEB und einen Rechner mit Docker, zum Beispiel einen Raspberry Pi, ein NAS oder einen Linux-Server. EasyTiley läuft in einem einzigen Container.

Ist EasyTiley kostenlos?

Ja. EasyTiley ist Open Source unter der MIT-Lizenz, ohne Konto, ohne Abo und ohne Cloud.

Funktioniert es mit HTTPS und Passwortschutz in FHEMWEB?

Ja. HTTPS (auch mit selbstsigniertem Zertifikat) und basicAuth werden unterstützt. Benutzername und Passwort bleiben auf dem Server und werden nie an den Browser geschickt.

Eignet es sich als Wand-Tablet-Dashboard?

Genau dafür ist es gebaut: Vollbild, Echtzeit-Updates per Push, Vibration und Klick-Ton beim Bedienen und ein Modus mit reduzierten Effekten für ältere Tablets.

Kann ich EasyTiley vorher ausprobieren?

Ja, in der Live-Demo mit simulierten Geräten – direkt im Browser, ohne Installation und ohne FHEM.

Gefällt dir EasyTiley?

Es ist kostenlos und quelloffen. Ein Stern, eine Idee oder ein Kaffee helfen dem Projekt.
