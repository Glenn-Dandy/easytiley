2. Die Software EasyTiley

Wenn du EasyTiley installierst, läuft es vollständig auf deinem eigenen Rechner oder Server. Für diese Installation bist du selbst verantwortlich, das Projekt hat keinen Zugriff darauf.

  • Gespeicherte Daten: Dashboards, Kacheln und Einstellungen liegen in einer SQLite-Datenbank auf deinem Server. Einige Anzeige-Einstellungen (z. B. Sprache) speichert dein Browser lokal (localStorage).
  • Verbindungen: EasyTiley spricht nur mit deinem FHEM-Server. Es werden keine Daten an das Projekt oder an Dritte gesendet.
  • Update-Prüfung: Nur wenn du auf der Über-Seite „Nach Update suchen“ tippst, fragt dein Browser bei api.github.com die neueste Version ab. Dabei erhält GitHub deine IP-Adresse und die Browser-Kennung.
  • Fehler melden / Idee vorschlagen: Die Knöpfe öffnen ein neues GitHub-Issue. Darin sind App-Version, Browser-Kennung und Bildschirmgröße vorausgefüllt. Du siehst alles vor dem Absenden und kannst es ändern oder löschen. Gesendet wird erst, wenn du das Issue selbst abschickst.
