Privacy Policy

Last updated: {{STAND}}

In short
  • EasyTiley is open source and runs on your own server. The project does not collect any data about you.
  • No account, no telemetry, no ads, no tracking and no analytics.
  • This project page is hosted on GitHub Pages, which technically receives your IP address.

1. Controller

This project page is run by the maintainer of the open-source project EasyTiley, Glenn-Dandy on GitHub. The easiest way to ask privacy questions is through the issues in the GitHub repository. A data protection officer is not required for this private project.

2. The EasyTiley software

When you install EasyTiley, it runs entirely on your own computer or server. You are responsible for that installation, and the project has no access to it.

  • Stored data: Dashboards, tiles and settings are kept in an SQLite database on your server. A few display settings (such as the language) are stored locally by your browser (localStorage).
  • Connections: EasyTiley only talks to your FHEM server. No data is sent to the project or to third parties.
  • Update check: Only when you tap “Check for updates” on the About page does your browser ask api.github.com for the latest version. GitHub receives your IP address and user agent in the process.
  • Report a bug / Suggest an idea: These buttons open a new GitHub issue pre-filled with the app version, browser user agent and screen size. You see everything before sending and can edit or remove it. Nothing is sent until you submit the issue yourself.

3. This project page and the live demo

Hosting: The site is served by GitHub Pages (GitHub Inc., 88 Colton Street, San Francisco, CA 94107, USA). When you visit it, GitHub processes technically required data such as your IP address, time of access, requested page and user agent to deliver the site and protect it from abuse. The legal basis is our legitimate interest in a secure, working project page (Art. 6(1)(f) GDPR). GitHub is certified under the EU-U.S. Data Privacy Framework. Details: GitHub's privacy statement. We do not get to see these server logs ourselves.

Version badge: To show the current version number, your browser makes one request to api.github.com.

No cookies, no tracking: The site sets no cookies and uses no analytics, advertising or social media services. Fonts and scripts are not loaded from third-party servers.

Local storage: Your chosen language and, in the live demo, your demo layout are only kept in your browser's storage (localStorage) and are never transmitted. In the demo you clear them with “Reset”, otherwise via your browser settings.

Google Search Console: The site contains a verification code for Google Search Console. It does not transmit any visitor data to Google.

4. Links to other services

The site links to GitHub, PayPal (donations) and the FullScreendy app. You only reach their sites when you click a link, and their own privacy policies apply there.

5. Contributions on GitHub

Issues, comments, stars and pull requests on GitHub are public and subject to GitHub's terms. Please do not post private data there, such as addresses, passwords or the URL of your FHEM server.

6. Your rights

Under the GDPR you have the right of access, rectification, erasure, restriction of processing, data portability and objection (Art. 15–21 GDPR). You can also lodge a complaint with a data protection supervisory authority (Art. 77 GDPR). As the project itself stores no personal data, such requests usually concern GitHub as the host.

7. Changes

If anything changes, we update this policy. Every earlier version can be traced in the version history on GitHub.
